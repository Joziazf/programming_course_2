ex1

Глобально:
#define N 5 -> константа для N, везде где она есть будет 5
typedef long int MyInt -> новый тип MyInt (новое название для long int)
double g(int, int) -> функция, возвращающая double и принимающая int-овые значения
int a -> глобальная целочисленная переменная

Внутри функции:
float a -> локальная переменная, тип число с плавающей точкой (тушит int a)
int d, int t -> две локальные целочисленные переменные
double m, n -> локальные переменные, тип число с плавающей точкой (в 2 раза точнее, чем float)
MyInt l -> локальная целочисленная переменная (больше чем int)
int a (в цикле) -> локальная целочисленная переменная

Вычисления:
n -->
n = l * N + a
Начальное значение: l = 0
a = 0: l += 0 -> l = 0
a = 1: l += 1 -> l = 1
a = 2: l += 2 -> l = 3
a = 3: l += 3 -> l = 6
a = 4: l += 4 -> l = 10
N = 5 (константа)
a = 3.14 (локальное обьявление переменной)
n = 10 * 5 + 3.14 = 53.14

m -->
m = g(d, t), где значение функции вычисляется по формуле a / d + t
в функции используется глобальная переменная a, 100 / 123 + 456
тк a и d целочисленные переменные, то результатом их деления будет целочисленное число
100 / 123 = 0
0 + 456 = 456

Ответ: n = 53.14, m = 456

ex2

Ошибки:
1. int *x, *y, *z, d -> происходит разыменование случайных объектов в памяти, указатели объявлены, но памяти для них нет
2. из первого пункта следует и вторая ошибка, при попытке записи данных в *x, *y, *z происходит ошибка доступа к памяти
3. if (x > y) и др -> сравнение адресов объектов, а не их значений
4. (d = *x; x = y; *y = d) и др -> x = y копирует адрес, а не значение
5. cout << "x = " .... -> ошибка вывода, выводится адрес в памяти, а не значение переменной

Задача программы:
Сортировка трёх чисел в порядке возрастания (x <= y <= z) и вычисление разницы между максимальным и минимальным значениями

(Для себя) -> Исправленный вариант закомментирован в main.cpp

Объяснения:
Указатель -> переменная, значением которой является адрес в памяти.
1) Может быть Null, либо не инициализирована;
2) Требует оператор *;
3) Могут менять адрес;
4) Синтаксис:
int *p;
double *q;

Ссылка -> альтернативное имя для объекта.
1) Должна быть сразу инициализирована;
2) Изменение значений по ссылке изменяют и исходный объект;
3) Не может быть переназначена на другой объект после инициализации;
3) Синтаксис:
int x = 5;
int &ref = x;
