## Слайд 1: Исходный код программы
Здесь представлен полный код. Далее мы будем рассматривать только те его части, которые работают в конкретный момент времени.

```cpp
#include <iostream>
using namespace std;

const int n = 3;
int P[n]; // Массив для текущей перестановки
int R[n]; // Массив флагов (0 - свободно, 1 - занято)

void per(int k) {
    for (int i = 0; i < n; i++) {
        if (R[i] == 0) {
            P[k] = i + 1;
            R[i] = 1;
            
            if (k == n - 1) {
                for (int j = 0; j < n; j++) cout << P[j] << " ";
                cout << endl;
            } else {
                per(k + 1);
            }
            R[i] = 0; // Шаг назад (отсечение)
        }
    }
}

int main() {
    for (int i = 0; i < n; i++) R[i] = 0;
    per(0);
    return 0;
}
```

**Выполняемый код:**

1. `main()`

## Слайд 3: Первый уровень (Выбор 1-го элемента)
> Мы находимся внутри `per(0)`. Цикл берет первое свободное число (`i=0`). Записываем его на позицию `k=0` и помечаем как занятое.

**Выполняемый код:**
```cpp
// Вызов: per(0)
for (int i = 0; i < n; i++) {
    if (R[i] == 0) {         
        P[k] = i + 1; // P[0] = 1
        R[i] = 1;     // R[0] = 1
        // ...
        per(k + 1);   // Вызов per(1) --->
```

**Статическая память:**
* `P`: `[ 1, ?, ? ]`
* `R`: `[ 1, 0, 0 ]`

**Стек вызовов:**
2. `per(0)` | Переменные: `k=0, i=0`
1. `main()`

## Слайд 4: Второй уровень (Выбор 2-го элемента)
> Мы вошли в `per(1)`. Число `1` уже занято (т.к. `R[0] == 1`), поэтому цикл переходит к `i=1`.

**Выполняемый код:**
```cpp
// Вызов: per(1)
// i=0 пропускаем, т.к. R[0] != 0
if (R[i] == 0) {         
    P[k] = i + 1; // P[1] = 2
    R[i] = 1;     // R[1] = 1
    // ...
    per(k + 1);   // Вызов per(2) --->
```

**Статическая память:**
* `P`: `[ 1, 2, ? ]`
* `R`: `[ 1, 1, 0 ]`

**Стек вызовов:**
3. `per(1)` | Переменные: `k=1, i=1`
2. `per(0)` | Переменные: `k=0, i=0`

## Слайд 5: Третий уровень (Выбор 3-го элемента)

**Выполняемый код:**

```cpp
// Вызов: per(2)
```

## Слайд 6: ПЕРВАЯ ПЕРЕСТАНОВКА НАЙДЕНА!
> Внутри `per(2)` срабатывает условие `k == n - 1` (т.е. 2 == 2). Массив `P` заполнен!

**Выполняемый код:**
```cpp
if (k == n - 1) {
    for (int j = 0; j < n; j++) cout << P[j] << " ";
    cout << endl; // <--- ВЫВОД В КОНСОЛЬ
}
```

**Консоль:**
`1 2 3`

**Память** остается без изменений. Функция готовится к шагу назад.

## Слайд 7: Шаг назад (Backtracking)
> Вывод завершен. В `per(2)` мы освобождаем ячейку `R[2] = 0` и возвращаемся в `per(1)`.

**Выполняемый код:**
```cpp
// Выходим из if (k == n - 1)...
        }
        R[i] = 0; // R[2] = 0 (Возврат состояния)
    }
} // Конец per(2), возврат в per(1)
```

**Статическая память:**
* `P`: `[ 1, 2, 3 ]` *(тройка осталась, но скоро перепишется)*
* `R`: `[ 1, 1, 0 ]`

**Стек вызовов:**
3. `per(1)` | Переменные: `k=1, i=1`
2. `per(0)` | Переменные: `k=0, i=0`

## Слайд 8: Продолжение работы на уровне 2
> Вернувшись в `per(1)`, мы освобождаем `R[1] = 0`. Цикл продолжается и переходит к `i=2`.

**Выполняемый код:**
```cpp
// Продолжение per(1)
        R[i] = 0; // R[1] = 0 (Шаг назад для двойки)
    }
// Следующий шаг цикла: i = 2
if (R[i] == 0) {
    P[k] = i + 1; // P[1] = 3
    R[i] = 1;     // R[2] = 1
    per(k + 1);   // Вызов per(2) --->
```

**Статическая память:**
* `P`: `[ 1, 3, 3 ]`
* `R`: `[ 1, 0, 1 ]`

**Стек вызовов:**
3. `per(1)` | Переменные: `k=1, i=2`
2. `per(0)` | Переменные: `k=0, i=0`

## Слайд 9: ВТОРАЯ ПЕРЕСТАНОВКА НАЙДЕНА!
> Снова заходим в `per(2)`. Находим единственное свободное число (`i=1`, то есть двойку), записываем её. Срабатывает условие вывода.

```cpp
// Вызов: per(2)
if (R[i] == 0) { // Нашли свободный i=1
```

## Слайд 10: Глубокий возврат к началу
> Пройдя шаги сброса `R[i]=0`, алгоритм завершает ветку для единицы и возвращается в самое начало — в функцию `per(0)`.

**Выполняемый код:**
```cpp
// Завершение циклов в per(2) и per(1)...
// Мы снова в per(0)!
        R[i] = 0; // R[0] = 0 (Освобождаем единицу!)
    }
// Следующий шаг цикла в per(0): i = 1
if (R[i] == 0) {
    P[k] = i + 1; // P[0] = 2  <--- Начало новой ветви
    R[i] = 1;     // R[1] = 1
    per(k + 1);   // Вызов per(1) --->
```

**Статическая память:**
* `P`: `[ 2, 3, 2 ]`
* `R`: `[ 0, 1, 0 ]`

**Стек вызовов:**
2. `per(0)` | Переменные: `k=0, i=1`
1. `main()`

## Слайд 11: Поиск третьей перестановки
> В `per(1)` мы забираем свободную единицу (`i=0`).  
> Затем в `per(2)` мы забираем оставшуюся тройку (`i=2`).  
> Происходит вывод результата.

**Выполняемый код:**
```cpp
// Последовательно выполняются:
P[1] = 1; R[0] = 1; // В per(1)
P[2] = 3; R[2] = 1; // В per(2)
// ... Вывод перестановки
```

**Консоль:**
`2 1 3`

**Статическая память (финал нашей иллюстрации):**
* `P`: `[ 2, 1, 3 ]`
* `R`: `[ 1, 1, 1 ]`

*(Далее алгоритм по аналогии сгенерирует 2 3 1, 3 1 2 и 3 2 1)*
