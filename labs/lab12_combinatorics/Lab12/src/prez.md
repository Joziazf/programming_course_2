## Слайд 1: Исходный код программы

```cpp
#include <iostream>
using namespace std;

const int n = 3;
int P[n]; // Массив для текущей перестановки
int R[n]; // Массив флагов

void per(int k) {
    for (int i = 0; i < n; i++) {
        if (R[i] == 0) {
            P[k] = i + 1;
            R[i] = 1;
            
            if (k == n - 1) {
                for (int j = 0; j < n; j++) cout << P[j] << " ";
                cout << endl;
            } else {
                per(k + 1);
            }
            R[i] = 0; // Шаг назад
        }
    }
}

int main() {
    for (int i = 0; i < n; i++) R[i] = 0;
    per(0);
    return 0;
}
```

**Выполняемый код:**

## Слайд 3: Первый уровень (Выбор 1-го элемента)
> Далее мы попадаем в функцию per(0). У нас идет цикл перебора от 0 до n, мы делаем проверку: если у нас флаг по текущему индексу i равен нулю (то есть число свободно), мы на позицию k записываем это число i + 1 и ставим флаг 1, типа число занято. И дальше запускаем функцию для следующего шага per(k + 1).

**Выполняемый код:**
```cpp
// Вызов: per(0)
for (int i = 0; i < n; i++) {
    if (R[i] == 0) {         
        P[k] = i + 1; // P[0] = 1
        R[i] = 1;     // R[0] = 1
        // ...
        per(k + 1);   // Вызов per(1) --->
```

**Статическая память:**
* `P`: `[ 1, ?, ? ]`
* `R`: `[ 1, 0, 0 ]`

**Стек вызовов:**
2. `per(0)`
1. `main()`

## Слайд 4: Второй уровень (Выбор 2-го элемента)
> Тут мы уже в per(1). Итерация цикла для i=0 не проходит проверку, потому что флаг там уже 1. Далее цикл доходит до i=1, проверка срабатывает, и мы на позицию k=1 ставим двойку. Заняли двойку, поставили флаг и снова вызываем рекурсию для per(2).

**Выполняемый код:**
```cpp
// Вызов: per(1)
// i=0 пропускаем, т.к. R[0] != 0
if (R[i] == 0) {         
    P[k] = i + 1; // P[1] = 2
    R[i] = 1;     // R[1] = 1
    // ...
    per(k + 1);   // Вызов per(2) 
```

**Статическая память:**
* `P`: `[ 1, 2, ? ]`
* `R`: `[ 1, 1, 0 ]`

**Стек вызовов:**
3. `per(1)`
2. `per(0)`

## Слайд 5: Третий уровень (Выбор 3-го элемента)
> Далее мы заходим в per(2). Тут первые два числа уже заняты флагами, поэтому цикл перебора доходит сразу до i=2. Проверка срабатывает, ставим на последнюю позицию тройку и меняем ей флаг на единицу.

**Выполняемый код:**
```cpp
// Вызов: per(2)
// i=0 и i=1 пропускаем
if (R[i] == 0) {         
    P[k] = i + 1; // P[2] = 3
    R[i] = 1;     // R[2] = 1
```

**Статическая память:**
* `P`: `[ 1, 2, 3 ]`
* `R`: `[ 1, 1, 1 ]`

**Стек вызовов:**
4. `per(2)`
3. `per(1)`
2. `per(0)`

## Слайд 6: ПЕРВАЯ ПЕРЕСТАНОВКА НАЙДЕНА!
> И вот тут у нас срабатывает проверка, если k равняется n - 1 (то есть мы дошли до конца массива), то мы просто через цикл выводим нашу готовую перестановку в консоль.

**Выполняемый код:**
```cpp
if (k == n - 1) {
    for (int j = 0; j < n; j++) cout << P[j] << " ";
    cout << endl; 
}
```

**Консоль:**
`1 2 3`

**Память** остается без изменений.

## Слайд 7: Шаг назад (Backtracking)
> После вывода мы ставим R[2] = 0, возвращая массив в первоначальный вид.  Функция per(2) отработала, и мы возвращаемся на шаг назад в per(1).

**Выполняемый код:**
```cpp
// Выходим из if (k == n - 1)...
        }
        R[i] = 0; // R[2] = 0 
    }
} // Конец per(2), возврат в per(1)
```

**Статическая память:**
* `P`: `[ 1, 2, 3 ]`
* `R`: `[ 1, 1, 0 ]`

**Стек вызовов:**
3. `per(1)`
2. `per(0)`

## Слайд 8: Продолжение работы на уровне 2
> Вернувшись в per(1), мы также ставим в ячейку ноль (освобождаем двойку). Далее цикл перебора идет на следующую итерацию i=2. Проверяем флаг, он свободен, значит ставим на позицию k=1 тройку и снова вызываем функцию для следующего шага per(2).

**Выполняемый код:**
```cpp
// Продолжение per(1)
        R[i] = 0; // R[1] = 0 (Шаг назад для двойки)
    }
// Следующий шаг цикла: i = 2
if (R[i] == 0) {
    P[k] = i + 1; // P[1] = 3
    R[i] = 1;     // R[2] = 1
    per(k + 1);   // Вызов per(2) 
```

**Статическая память:**
* `P`: `[ 1, 3, 3 ]`
* `R`: `[ 1, 0, 1 ]`

**Стек вызовов:**
3. `per(1)`
2. `per(0)`

## Слайд 9: ВТОРАЯ ПЕРЕСТАНОВКА НАЙДЕНА!
> Снова зашли в per(2). Тут у нас свободна только двойка (i=1), так как единицу и тройку мы уже заняли. Ставим двойку, у нас опять k равняется n - 1, поэтому рисуем вторую готовую перестановку.

**Выполняемый код:**
```cpp
// Вызов: per(2)
if (R[i] == 0) { // Нашли свободный i=1
    P[k] = i + 1; // P[2] = 2
    R[i] = 1;     // R[1] = 1
```

**Консоль:**
`1 3 2`

**Статическая память:**
* `P`: `[ 1, 3, 2 ]`
* `R`: `[ 1, 1, 1 ]`

## Слайд 10: Глубокий возврат к началу
> Далее идет жесткий возврат. Мы сбрасываем флаги в per(2), потом цикл в per(1) заканчивается, мы и там ставим 0, возвращая в первоначальный вид. По итогу мы выходим в самую первую функцию per(0). Там мы освобождаем единицу и идем на следующую итерацию цикла i=1. Ставим двойку на первое место и запускаем рекурсию заново через per(1).

**Выполняемый код:**
```cpp
// Завершение циклов в per(2) и per(1)...
// Мы снова в per(0)!
        R[i] = 0; // R[0] = 0 
    }
// Следующий шаг цикла в per(0): i = 1
if (R[i] == 0) {
    P[k] = i + 1; // P[0] = 2  <--- Начало новой ветви
    R[i] = 1;     // R[1] = 1
    per(k + 1);   // Вызов per(1)
```

**Статическая память:**
* `P`: `[ 2, 3, 2 ]`
* `R`: `[ 0, 1, 0 ]`

**Стек вызовов:**
2. `per(0)`
1. `main()`

## Слайд 11: Поиск третьей перестановки
> Ну и по сути дальше то же самое. В per(1) мы находим свободную единицу, ставим ее, идем в per(2), там ставим оставшуюся тройку и выводим третью перестановку. И так далее, пока все варианты не переберутся.

**Выполняемый код:**
```cpp
// Последовательно выполняются:
P[1] = 1; R[0] = 1; // В per(1)
P[2] = 3; R[2] = 1; // В per(2)
```

**Консоль:**
`2 1 3`

**Статическая память:**
* `P`: `[ 2, 1, 3 ]`
* `R`: `[ 1, 1, 1 ]`

*(Далее алгоритм по аналогии сгенерирует 2 3 1, 3 1 2 и 3 2 1)*
